# Bardo Rogue

The language of the game's world and run loop. The game is a deterministic hub → Greek-gate run loop; this glossary names the concepts that loop is built from.

## Language

**The Bardo**:
The waystation between death and what comes next — the explorable hub where every run begins and ends. It is a sacred dead place, not a settlement.
_Avoid_: Town, village, hub town

**Island**:
One walkable landmass of the Bardo, floating in the Void and linked to others by bridges or stairs.
_Avoid_: Zone, area, platform

**The Void**:
The starfield space every room floats in. Nothing walkable; it frames every island and is never a solid black rectangle.
_Avoid_: Background, black space, letterbox

**Inhabitant**:
A silent presence dwelling in the Bardo — a figure you approach and read, not a dialogue system.
_Avoid_: NPC, vendor, shopkeeper

**Pantheon**:
One mythology's underworld tradition — Greek, Norse, Aztec, Egyptian — each with its own art style. The Bardo and the hero belong to no pantheon.

**Ferryman**:
The unnamed inhabitant moored at the Bardo's void pier — the ferryman archetype of every death tradition, never Charon. Charon is a Greek realm boss.
_Avoid_: Charon (in the Bardo), boatman

**Realm**:
One named region of a pantheon's underworld that a run descends through. The vertical slice's realm is Greek (Acheron, Lethe, Asphodel, Charon, Minos, Hecate); other pantheons follow.

**Seal**:
A visibly locked place in the Bardo — a chained bridge, a dead tower — that opens across runs. You can always see what you cannot yet reach.
_Avoid_: Locked door, gate (that word belongs to the Gate)

**The Gate**:
The red gate in the Bardo through which every run begins. Pantheon-neutral stone; only its marks and light take on the destination realm.

**Run**:
One descent through the gate: rooms, boons, rites, boss, and the return to the Bardo.
