# Approved masters

An image lands here only by human decision. Everything generated afterwards is conditioned on this
pool, so consistency compounds instead of being re-argued per asset — and so does any fault that gets
approved by accident. This is the one deliberate human checkpoint in the pipeline; spend it.

Generation resolves this pool by stable path order, never modification time. Retro Diffusion receives
at most the first four PNGs; PixelLab supports one style image and receives the first of that same
four-image prefix. Name files deliberately: path order is provider input order.
