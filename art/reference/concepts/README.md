# Concept references — the named bar

These nine images are the visual bar for the graphics overhaul (VERTICAL_SLICE_PLAN.md Revision 6,
2026-08-29). They are **references, not assets**: never compiled, never shipped, never entered into
`art/approved/`. The blind-critic protocol (§11.2) uses them as the reference side of every exhibit.

They are concept art — the game does not copy their isometric projection or their canvas scale. What
the game takes from them is measured by the bible: value structure against the void, gold-vs-indigo
light, monumental set pieces over a small figure (~9 % of frame height), and the numinous accents
now canonized as the `numen` ramp (§1.2).
